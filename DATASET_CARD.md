# FinSight AI Synthetic Financial Intelligence Dataset

This dataset supports the FinSight AI portfolio project, a multi-agent financial intelligence platform.

## Files

- `companies.csv`: Synthetic company fundamentals
- `news.csv`: Synthetic finance headlines for sentiment scoring
- `filings.csv`: Filing-style company text for RAG retrieval

## Use Cases

- Multi-agent financial analysis
- Retrieval-augmented generation
- Quantitative signal modelling
- Investment-research dashboard prototypes
- FastAPI model-serving demos

## Important Note

All data is synthetic and created for education. It should not be used for real investing.
